# Noosh e jan

Demo website for *Noosh e jan: Recipes to nourish your soul* by Zhahla Mohamed.

Open `index.html` in a browser. No build step.

- `js/recipes.js`: all recipe content. Copy an entry to add a recipe.
- `css/styles.css`: palette, type and layout.
- `images/`: photos (see `images/README.md` for file names).
